## 화면 목록

| 번호 | 경로 | 화면 | 비고 |
|---|---|---|---|
| 1 | `/` | 메인 페이지 (프로필 & 링크 관리 홈) | 비로그인 시 로그인 안내 화면(`Google로 로그인하기`), 로그인 시 상단 프라이머리 `링크 추가` CTA 및 Firestore(`users/{uid}/links`) 연동 링크 목록(`getDocs` 최신순), 항상 표시되는 수정·삭제 버튼, 인라인 수정(`updateDoc`), 삭제 확인 모달(`deleteDoc`), 로딩 스피너 |
| 2 | `/links` | 링크 목록 전용 유틸리티 페이지 | Apple 18px 카드 + 공용 `LinkCard` 정적 데모 목록 (`dummyLinks` 6종 유지) |
| 3 | `/[username]` | 공개 프로필 화면 (예: `/gildong`) | 읽기 전용 방문자 뷰, 빈 상태, 404 상태 포함 |

## 3. 공개 프로필 메인 화면 (`/[username]`, 예: `/gildong`)

방문자가 SNS 프로필 링크를 타고 들어왔을 때 보는 기본 멀티링크 화면입니다. (`Apple 클래식` 기본 테마 기준, 콘텐츠 최대 폭 `680px` 가운데 정렬)

```text
========================================================================
[ 상단 영역: Light Tile ]  배경 #ffffff (또는 #f5f5f7) · 텍스트 #1d1d1f
========================================================================
  MyLink                                            ( 페이지 공유 )

                            (   아바타   )         <-- 원형 120x120px, shadow-product
                               홍길동
                            @gildong

             안녕하세요! 작은 기능 하나에도 최선을 다해
               만들어 보는 초보 웹 개발자 홍길동입니다.

                  (IG)   (YT)   (GH)   (Mail)

========================================================================
[ 하단 영역: Dark Tile ]   배경 #272729 · 카드 #2a2a2c · 강조 #2997ff
========================================================================

  ── 추천 링크 ───────────────────────────────────────────────────────
  +------------------------------------------------------------------+
  |  [GitHub]   GitHub 공부 저장소                              [›]  |
  +------------------------------------------------------------------+
  +------------------------------------------------------------------+
  |  [Blog]     오늘의 개발 블로그 (TIL)                        [›]  |
  +------------------------------------------------------------------+

------------------------------------------------------------------------
                 MyLink로 나만의 페이지 만들기 ›
========================================================================
```

### 3-1. 예외 상태: 존재하지 않는 username (404)

```text
========================================================================
  배경 #f5f5f7 · 중앙 정렬 카드

                        페이지를 찾을 수 없습니다
               요청하신 마이링크 페이지가 존재하지 않습니다.

            (  홈으로 가기 /  )     (  예시 보기 /gildong  )
========================================================================
```

> **라우팅 처리**: 대문자(`/Gildong`) 또는 변경 전 과거 주소(`/gildong_study`) 접속 시 최신 활성 주소(`/gildong`)로 자동 리다이렉트하며, 삭제된 `/admin` 접속 시 존재하지 않는 경로로 404 안내 화면이 표시됩니다.
