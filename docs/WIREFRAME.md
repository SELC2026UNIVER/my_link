|---|---|---|---|
| 1 | `/[username]` | 공개 프로필 메인 화면 (방문자 뷰) | 기본 상태, 빈 상태, 404 포함 |

| 4 | `/admin` (PC) | 대시보드 편집기 — 2단 분할 | 프로필·링크·소셜·섹션 CRUD / 테마 / 통계 + 실시간 모바일 목업 |

## 1. 공개 프로필 메인 화면 (`/[username]`, 예: `/gildong`)

방문자가 SNS 프로필 링크를 타고 들어왔을 때 보는 기본 화면입니다. (`Apple 클래식` 기본 테마 기준, 콘텐츠 최대 폭 `680px` 가운데 정렬)

```text
========================================================================
[ 상단 영역: Light Tile ]  배경 #ffffff (또는 #f5f5f7) · 텍스트 #1d1d1f
========================================================================

                            (   아바타   )         <-- 원형 120x120px, shadow-product
                            ( 120 x 120  )             미등록 시 이름 첫 글자 기본 아바타

                              홍길동               <-- 이름 (displayName, 1~30자)
                           @gildong                <-- 사용자명 (@username)

             안녕하세요! 작은 기능 하나에도 최선을 다해
               만들어 보는 초보 웹 개발자 홍길동입니다. <-- 자기소개 (최대 150자, 선택)

                  (IG)   (YT)   (GH)   (Mail)      <-- 소셜 미디어 배치 (F-08, 최대 8개)
                                                       각 버튼 최소 터치 영역 44x44px

========================================================================
[ 하단 영역: Dark Tile ]   배경 #272729 · 카드 #2a2a2c · 강조 #2997ff
========================================================================

  ── 작은 연습 작품 ───────────────────────────────────────────────────
     ^ 섹션 구분 헤더 (F-09: 얇은 헤어라인 rgba(255,255,255,0.12) + 소제목)

  +------------------------------------------------------------------+
  |  [아이콘]   미니 할 일 메모장                                [›] |  <-- 카드 18px 둥근 모서리
  +------------------------------------------------------------------+      (테마 설정 시 pill형 가능)
                                                                          최소 높이 44px 이상
  +------------------------------------------------------------------+
  |  [아이콘]   동네 카페 메뉴판 클론 코딩                       [›] |
  +------------------------------------------------------------------+

  ── 공부 & 소통 ─────────────────────────────────────────────────────

  +------------------------------------------------------------------+
  |  [GitHub]   GitHub 공부 기록 보러 가기                       [›] |  <-- 클릭 시 통계 +1 후
  +------------------------------------------------------------------+      새 탭(_blank) 이동

  +------------------------------------------------------------------+
  |  [Email]    응원과 조언 이메일 보내기                        [›] |  <-- mailto: 메일 앱 실행
  +------------------------------------------------------------------+


------------------------------------------------------------------------
                 MyLink로 나만의 페이지 만들기 ›                       <-- Sky Link Blue (#2997ff)
                                                                          클릭 시 랜딩(/) 이동
========================================================================
```

### 1-1. 예외 상태: 등록된 링크 0개 / 존재하지 않는 username (404)

```text
[ 링크 0개 상태 (하단 Dark Tile 내부) ]
  (프로필 영역은 정상 표시)

                     아직 등록된 링크가 없습니다.

------------------------------------------------------------------------
[ 404 상태 (존재하지 않는 /unknown_user 접속 시) ]
  배경 #f5f5f7 · 중앙 정렬 카드

                        페이지를 찾을 수 없습니다
               요청하신 마이링크 페이지가 존재하지 않습니다.

            (  홈으로 가기 /  )     (  예시 보기 /gildong  )
```

## 3. 데모 이메일 로그인 (`/login`) & 온보딩 (`/onboarding`)

### 3-1. 로그인 (`/login`) — 2단계 전환 & 원클릭 데모

```text
========================================================================
배경 #f5f5f7 · 중앙 카드 (#ffffff, 18px 둥근 모서리, 1px #e0e0e0)
========================================================================

  [ Step 1: 이메일 입력 ]
    마이링크 시작하기
    이메일만으로 간편하게 로그인하거나 새 페이지를 만드세요.

    이메일
    +------------------------------------------------------+
    | creator@example.com                                  |  <-- 오류 시 테두리 #e30000
    +------------------------------------------------------+
    (!) 올바른 이메일 형식이 아닙니다                          <-- 오류 문구 (#e30000)

    (            인증코드 받기 (#0066cc)            )
    ────────────────────── 또는 ──────────────────────
    (      데모 계정(/gildong)으로 바로 체험하기     )

  --------------------------------------------------------------------

  [ Step 2: Mock 6자리 인증코드 입력 ]
    +------------------------------------------------------+
    | [데모 안내] 발송된 인증코드: 482910 (유효시간 09:58)  |  <-- 서버 없이 화면 내 안내
    +------------------------------------------------------+

    인증코드 6자리
    +------------------------------------------------------+
    | 482910                                               |
    +------------------------------------------------------+
    (!) 인증코드가 올바르지 않습니다 (남은 시도 4회)

    (                확인 (#0066cc)                 )
    [코드 다시 받기 (60초 후)]        [이메일 다시 입력]
========================================================================
```

### 3-2. 첫 로그인 온보딩 (`/onboarding`)

```text
========================================================================
배경 #f5f5f7 · 중앙 카드 (#ffffff, 18px 둥근 모서리)
========================================================================

    내 마이링크 주소를 정해 주세요
    나중에 대시보드에서 언제든 바꿀 수 있습니다. (이름은 주소로 자동 설정)

    mylink.app / [ my_studio                              ]
    (!) 이미 사용 중이거나 사용할 수 없는 이름입니다           <-- 중복·예약어 시 #e30000

    * 영문 소문자, 숫자, 밑줄(_), 마침표(.) 3~20자

    (               시작하기 (#0066cc)               )
========================================================================
```

## 4. 대시보드 편집기 (`/admin`) — PC 2단 분할 (≥ 1024px)

### 4-1. `[프로필 · 링크]` 탭 (인라인 추가/수정 · 오류 · 삭제 Undo 포함)

```text
========================================================================
[ 상단 바 ]  배경 #ffffff / #f5f5f7 · 높이 56px
  MyLink Admin   내 주소: mylink.app/my_studio [열기 ↗]     [로그아웃]
------------------------------------------------------------------------
  [ 프로필 · 링크 ]    [ 테마 ]    [ 통계 ]          |  실시간 미리보기
========================================================================
[ 좌측: 편집 영역 (약 60%) ]              | [ 우측: 모바일 목업 (약 40%) ]
                                          |
  1) 프로필 카드 (#ffffff, 18px)          |   +------------------------+
  +------------------------------------+  |   |  9:41        [모바일]  |
  | (아바타) [사진 변경]  이름: 김크리   |  |   |------------------------|
  | 주소: @my_studio [변경]             |  |   |       ( 아바타 )       |
  | 소개: 크리에이터 공간입니다 (11/150) |  |   |        김크리          |
  |                     ( 프로필 저장 ) |  |   |      @my_studio        |
  +------------------------------------+  |   |   크리에이터 공간입니다  |
                                          |   |    (IG) (YT) (Mail)    |
  2) 소셜 미디어 배치 (최대 8개)           |   |------------------------|
  +------------------------------------+  |   | [Dark Tile]            |
  | (IG) Instagram  [수정] [삭제]       |  |   |  ── 추천 콘텐츠 ──     |
  | (YT) YouTube    [수정] [삭제]       |  |   |  +------------------+  |
  | (+ 소셜 추가)                       |  |   |  | [YT] 내 유튜브 › |  |
  +------------------------------------+  |   |  +------------------+  |
                                          |   |  +------------------+  |
  3) 링크 & 섹션 목록                     |   |  | [GH] 포트폴리오 ›|  |
  (+ 링크 추가)   [+ 섹션 헤더 추가]      |   |  +------------------+  |
                                          |   |                        |
  * [+ 링크 추가] 클릭 시 상단 인라인 폼:  |   |  MyLink로 만들기 ›     |
  +------------------------------------+  |   +------------------------+
  | 제목: [ 내 유튜브 채널            ] |  |   * 목업 내 클릭은
  | URL : [ not-a-url          ] (빨강) |  |     통계에 합산되지 않음
  | (!) 올바른 URL 형식이 아닙니다       |  |
  | 아이콘: [YouTube ▾] (도메인 자동추천)|  |
  |                [취소]   ( 저장 )    |  |
  +------------------------------------+  |
                                          |
  * 등록된 항목 목록 (드래그 & 버튼 정렬): |
  +------------------------------------+  |
  | ⋮⋮ [헤더] 추천 콘텐츠  [▲][▼][수정][삭제]
  +------------------------------------+  |
  | ⋮⋮ [YT] 내 유튜브 채널 [▲][▼][수정][삭제]
  |    https://youtube.com/@mystudio   |  |
  +------------------------------------+  |
  | ⋮⋮ [인라인 수정 전환 상태 예시]     |  |
  |    제목: [ 포트폴리오             ] |  |
  |    URL : [ https://github.com/... ] |  |
  |    아이콘: [GitHub ▾]   [취소](저장)|  |
  +------------------------------------+  |
                                          |
========================================================================
[ 하단 플로팅 토스트 (삭제 확인 모달에서 '삭제' 클릭 후 5초간 표시) ]
  +------------------------------------------------------------------+
  |  삭제되었습니다                                [ 실행 취소 ] (X) |
  +------------------------------------------------------------------+
```

  +-------------------+  +-------------------+
  +-------------------+  +-------------------+
  | [ ] 미드나잇 다크  |  | [ ] 소프트 블루    |
  | 전체 다크 타일     |  | 은은한 블루 틴트   |

## 5. 대시보드 편집기 (`/admin`) — 모바일 뷰 (≤ 1023px)

```text
+----------------------------------+
| MyLink Admin     /my_studio [↗]  |
|----------------------------------|
|  [  편집  ]   |   [ 미리보기 ]   |  <-- 상단 탭 전환 (2단 분할 대신 1열)
|----------------------------------|
|  [프로필·링크] [테마] [통계]     |  <-- '편집' 탭 활성 시 표시
|                                  |
|  +----------------------------+  |
|  | 프로필 카드                |  |
|  +----------------------------+  |
|  (+ 링크 추가) [+ 섹션 헤더]     |
|  +----------------------------+  |
|  | ⋮⋮ [YT] 내 유튜브          |  |
|  |    [▲] [▼] [수정] [삭제]   |  |  <-- 모든 버튼 최소 44x44px
|  +----------------------------+  |
+----------------------------------+
```
