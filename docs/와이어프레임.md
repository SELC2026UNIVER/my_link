## 1. 방문자 공개 프로필 메인 화면 (`/[username]`, 예: `/gildong`)

SNS 프로필 링크를 통해 들어온 방문자가 보는 메인 멀티링크 화면입니다.
콘텐츠 최대 폭은 `680px` 가운데 정렬이며, 기본 테마(`Apple 클래식`)에서는 상단 라이트 타일과 하단 다크 타일의 배경색 전환이 구분선 역할을 합니다.

### 1.1 정상 상태 (PC · 모바일 공통)

```text
========================================================================
[ 상단 영역: Light Tile ]  배경 #ffffff (또는 #f5f5f7) · 텍스트 #1d1d1f
========================================================================

                            (   아바타   )         <-- 원형, shadow-product
                            ( 120 x 120  )             미등록 시 이름 첫 글자

                              홍길동               <-- 이름 (displayName, 1~30자)
                           @gildong                <-- 사용자명 (@username)

             안녕하세요! 작은 기능 하나에도 최선을 다해
               만들어 보는 초보 웹 개발자 홍길동입니다. <-- 자기소개 (최대 150자)

                  (IG)   (YT)   (GH)   (Mail)      <-- 소셜 미디어 배치 (최대 8개)
                                                       각 버튼 최소 44x44px

========================================================================
[ 하단 영역: Dark Tile ]   배경 #272729 · 카드 #2a2a2c · 강조 #2997ff
========================================================================

  ── 작은 연습 작품 ───────────────────────────────────────────────────
     ^ 섹션 구분 헤더 (얇은 헤어라인 rgba(255,255,255,0.12) + 소제목)

  +------------------------------------------------------------------+
  |  [아이콘]   미니 할 일 메모장                                [›] |  <-- 카드 18px 둥근 모서리
  +------------------------------------------------------------------+      (테마에 따라 pill형 가능)
                                                                          최소 높이 44px 이상
  +------------------------------------------------------------------+
  |  [아이콘]   동네 카페 메뉴판 클론 코딩                       [›] |
  +------------------------------------------------------------------+

  ── 공부 & 소통 ─────────────────────────────────────────────────────

  +------------------------------------------------------------------+
  |  [GitHub]   GitHub 공부 기록 보러 가기                       [›] |  <-- 클릭 시 통계 누적 후
  +------------------------------------------------------------------+      새 탭(_blank) 이동

  +------------------------------------------------------------------+
  |  [Email]    응원과 조언 이메일 보내기                        [›] |  <-- mailto: 메일 앱 실행
  +------------------------------------------------------------------+

------------------------------------------------------------------------
                 MyLink로 나만의 페이지 만들기 ›                       <-- Sky Link Blue (#2997ff)
                                                                          클릭 시 랜딩(/) 이동
========================================================================
```

### 1.2 빈 상태 & 404 예외 상태

```text
[ 등록된 링크가 0개인 경우 (Dark Tile 내부) ]
  "아직 등록된 링크가 없습니다"

[ 존재하지 않는 username 접속 시 (/unknown_user) ]
========================================================================
  404 — 페이지를 찾을 수 없습니다
  요청하신 주소를 찾을 수 없거나 주소가 변경되었을 수 있습니다.

       (  홈으로 이동 /  )     (  예시 보기 /gildong  )
========================================================================
```

> **라우팅 처리**: 대문자(`/Gildong`) 또는 변경 전 과거 주소(`/old_name`)로 접속 시 최신 활성 주소(`/gildong`)로 자동 리다이렉트합니다.

  +------------------------------------------------------------------+
  |  MyLink 시작하기                                                 |
